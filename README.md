# zepto-sql-data-analysis
SQL data analysis project using PostgreSQL to analyze Zepto product data, pricing, discounts, inventory, and estimated revenue.
**Project Overview**

This project analyzes Zepto product data using PostgreSQL to derive business insights related to product pricing, discounts, inventory, availability, and estimated revenue.

**Tools & Technologies**
PostgreSQL
pgAdmin 4
SQL
GitHub
Dataset

The dataset contains information about Zepto products, including:

Category
Product name
MRP
Discount percentage
Weight
Stock availability
Quantity
Business Questions

**Some of the questions analyzed:**

What are the different product categories?
What are the highest and lowest product prices?
What is the average discount percentage?
Which category has the highest average discount?
Which products have the highest discounts?
Which products are out of stock?
What is the estimated revenue?
Which categories generate the highest estimated revenue?
Which products have the highest inventory?
What are the most expensive products?
